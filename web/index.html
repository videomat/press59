Questions

Does it break Caps Lock?

No. Tap Caps Lock quickly on its own and capitals toggle as always. It only becomes Hyper while you hold it and press another key.

Why does it need Accessibility access?

To catch a shortcut before the app you’re typing in sees it — that’s what keeps a stray letter from being typed. Press59 never records or sends what you type.

Why isn’t it on the Mac App Store?

Apps that intercept keystrokes can’t run in the App Store sandbox, so Press59 is distributed directly from this site.

Is it open source?

Yes. Press59 is free software under the GPL-3.0 license, and the app, this website and the release scripts are all on GitHub. It’s a small tool built for myself with Claude Code, shared as is: issues welcome, no promises.

Can I use it alongside Raycast or Alfred?

Yes. Turn off any other Hyper key setting so only one app owns Caps Lock, then use Hyper shortcuts in those apps as usual.

Does it replace Rectangle or Magnet?

For halves, thirds, quarters, filling the screen and centering, yes. If you’d rather keep your window manager, turn off “Caps Lock + arrow keys move windows” in Settings and Caps Lock + arrows and Return go out as ⌃⌥⇧⌘ + key again.

Will it mess with my other key remaps?

No. Press59 adds only Caps Lock to the keys macOS remaps, and removes only that when you quit. Remaps from Karabiner-Elements, your own scripts or System Settings stay as they are. The one exception is Caps Lock itself: if another tool remaps it, Press59 replaces that mapping, so turn it off in the other tool first.
